# Enterprise AI Quarterly Dashboard

Responsive React + Vite app presenting the **Enterprise AI: What Changed This Quarter (Jun–Aug 2025)** update.
All data lives in local JSON; no analytics or network calls.

## Setup
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build & Preview
```bash
npm run build
npm run preview
```

## Notes
- Project scaffolded with `npm create vite@latest ai-quarterly-dashboard -- --template react-ts`.
- Tailwind CSS via `tailwindcss`, `postcss`, `autoprefixer` (`npx tailwindcss@3.4.4 init -p`).
- Run locally or on any static host after `npm run build`.
